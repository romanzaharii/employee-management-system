# Employee Management System

Console Java application for employee management.

## Features

- Add employees
- Delete employees
- Update employee data
- Print employee table
- Sort and filter employee data
- Calculate salary, premium, taxes and net salary
- Save data to file
- Import data from file

## Technologies

- Java
- OOP
- Collections
- Streams
- File IO
- Serialization

## How to run

Open the project in IntelliJ IDEA and run `Main.java`.
